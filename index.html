Como colocar no UOL Mail Pro

  1. Clique em Copiar assinatura, acima.
  2. No UOL Mail Pro, clique na engrenagem (Configurações) e depois em Assinatura.
  3. Apague a assinatura antiga, clique dentro da caixa e aperte Ctrl+V. Deve aparecer a imagem azul, não um texto.
  4. Clique em Salvar e envie um e-mail de teste para conferir.

Onde as imagens ficam hospedadas

Vale para uma pessoa e para o lote. Se esta ferramenta estiver aberta pelo GitHub Pages, o endereço já vem preenchido.

Como hospedar no GitHub
  1. Repositório público assinaturas. Envie os PNGs (Add file → Upload files, até 100 arquivos por vez) sem renomear.
  2. Envie também esta ferramenta com o nome index.html e, no modo lote, o arquivo equipe.json. Com ele, cada funcionário escolhe o próprio nome numa lista.
  3. Settings → Pages → branch main → Save, e marque Enforce HTTPS. Publica em 1 a 2 minutos.
  4. Nunca apague nem renomeie imagens antigas: e-mails já enviados continuam usando elas.
Publicação automática

Conexão com o GitHub

Com a conexão feita, o botão "Publicar no GitHub" envia as imagens direto para a pasta acima, sem baixar nem arrastar arquivos. Nada é apagado: arquivos novos são criados, os alterados são substituídos e os iguais ficam como estão.

Não conectado
Como criar a chave (uma vez só)
  1. No GitHub: foto do perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nome: assinaturas. Validade: até 1 ano (anote a data para renovar).
  3. Repository access: Only select repositories → escolha só assinaturas.
  4. Permissions → Repository permissions → Contents: Read and write. Não marque mais nada.
  5. Generate token, copie a chave (começa com github_pat_) e cole no campo acima. O GitHub só mostra a chave uma vez.

A chave nunca vai para o arquivo publicado nem para o equipe.json. Ela fica só neste navegador, e só se você marcar "Lembrar". Use este recurso apenas no seu computador. Se a chave vazar, apague-a no GitHub e crie outra: ela só dá acesso a este repositório.
